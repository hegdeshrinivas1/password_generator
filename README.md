# 🔐 Python Password Generator

A simple Python program that generates random passwords based on the number of letters, symbols, and numbers entered by the user.

## Features

* Custom password length
* Uppercase and lowercase letters
* Numbers and special characters
* Randomly shuffles characters

## Technologies

* Python 3
* `random` module

## Run

```bash
python password_generator.py
```

## Example

```text
How many letters? 6
How many symbols? 2
How many numbers? 3

```
